# 갈피 — 화면 설계서 (Screen Specification)

> 용도: **Claude Design이 각 화면을 "어떻게 그릴지" 참고하는 문서.**
> 각 화면의 목적, 구성 요소, 레이아웃, 상태(빈 화면/로딩/에러)를 정의한다.
> 실제 색상·폰트 규칙은 `05_디자인시스템.md` 참고.

---

## 화면 목록 (MVP 기준)

| ID | 화면 | 소속 | 우선순위 |
|---|---|---|---|
| S-01 | 로그인 | Auth | ⭐ |
| S-02 | 회원가입 | Auth | ⭐ |
| S-03 | 내 책장 (홈) | Tab1 | ⭐ |

## S-01. 로그인 ⭐

**목적**: 기존 사용자가 로그인한다.

**구성 요소**
- 상단: 앱 로고 + "갈피" 타이틀 + 짧은 태그라인("좋아하는 구절을 담아두는 곳")
- 이메일 입력 필드
- 비밀번호 입력 필드 (가림 처리, 보기 토글)
- [로그인] 기본 버튼 (전체 너비)
- 하단: "계정이 없으신가요? 회원가입" 텍스트 링크 → S-02

**상태**
- 로딩: 로그인 버튼에 스피너, 입력 비활성화
- 에러: 필드 아래 또는 상단에 "이메일 또는 비밀번호가 올바르지 않습니다"

**레이아웃**: 세로 중앙 정렬, 여백 넉넉히. 키보드 올라올 때 입력 필드 가리지 않게.

---

## S-02. 회원가입 ⭐

**목적**: 신규 계정 생성.

**구성 요소**
- 상단: 뒤로가기 + "회원가입" 타이틀
- 이메일 입력 (형식 검증 실시간)
- 비밀번호 입력 (8자 이상 안내)
- 닉네임 입력 (2~20자)
- [가입하기] 기본 버튼
- 하단: "이미 계정이 있으신가요? 로그인" → S-01

**상태**
- 각 필드별 인라인 유효성 메시지 (예: "이미 사용 중인 닉네임입니다")
- 로딩: 버튼 스피너

---

## S-03. 내 책장 (홈) ⭐

**목적**: 내가 꽂은 책들을 표지 그리드로 진열. 앱의 첫인상.

**구성 요소**
- 상단: "내 책장" 타이틀 + (우측) 검색/추가 아이콘
- **책 표지 그리드** (2~3열)
  - 각 카드: 표지 이미지, 제목(1~2줄), "대사 N개" 뱃지
  - 표지 없는 MANUAL 책: 기본 표지(제목 텍스트를 표지처럼)
- 우하단: [+] 플로팅 버튼 → S-04 (책 추가)

**상태**
- **빈 화면 (중요)**: 책이 하나도 없을 때 → 일러스트 + "첫 책을 책장에 꽂아보세요" + [책 추가] 버튼. (첫 사용자 경험이라 특히 신경)
- 로딩: 스켈레톤 카드 (그리드 자리에 회색 박스)
- 에러: "책장을 불러오지 못했습니다" + 재시도 버튼

**레이아웃**: 그리드 카드 간격 일정, 표지 비율 통일(책 표지는 보통 세로 2:3).

---

## S-04. 책 추가 ⭐

**목적**: 도서 API 검색 또는 직접 등록으로 책장에 책 추가.

**구성 요소**
- 상단 탭 또는 세그먼트: [검색으로 추가] / [직접 등록]
- **검색 탭**:
  - 검색 입력창 (자동 포커스)
  - 검색 결과 리스트: 각 행에 표지 썸네일 + 제목 + 저자, 우측 [추가] 버튼
- **직접 등록 탭** (웹소설용):
  - 제목 입력 (필수)
  - 작가 입력
  - 유형 선택: 소설 / 웹소설
  - 표지 이미지 업로드 (선택, 없으면 기본 표지)
  - [등록] 버튼

**상태**
- 검색 전: "책 제목을 검색해보세요" 안내
- 검색 중: 로딩 스피너
- 결과 없음: "검색 결과가 없어요. 직접 등록해보세요" (직접등록 탭으로 유도 — 웹소설 배려)
- 이미 있는 책: [추가] 버튼이 [책장에 있음]으로 표시

---

## S-05. 책 상세 = 대사 모아보기 ⭐ (핵심 화면)

**목적**: 책을 "펼치듯" 열어 그 책의 대사들을 한 번에 본다. 앱 컨셉의 심장.

**구성 요소**
- 상단 헤더: 뒤로가기
- **책 정보 영역**: 큰 표지 + 제목 + 저자 + (책장에서 빼기 옵션)
- **"이 책의 대사" 섹션**:
  - 대사 카드 리스트 (세로)
  - 각 카드: 등장인물 이름, 대사 본문(2~3줄 미리보기), 알림 설정 시 🔔 아이콘, 메모 있으면 표시
  - 카드 탭 → S-07 (대사 상세)
- 우하단: [+] → S-06 (이 책에 대사 추가)

**상태**
- 빈 화면: "아직 이 책에 담은 대사가 없어요" + [대사 추가]
- 로딩: 스켈레톤

**레이아웃**: 대사 본문이 주인공 — 가독성 좋은 큰 글씨, 인용구 느낌의 스타일(따옴표 장식 등).

---

## S-06. 대사 작성/수정 ⭐

**목적**: 대사를 입력/편집한다.

**구성 요소**
- 상단: 취소 / "대사 기록" / 저장
- 책 표시 (어느 책에 기록 중인지 — 상단에 표지+제목 작게)
- 등장인물 입력 (선택)
- **대사 본문 입력** (여러 줄, 큰 영역 — 메인)
- 메모 입력 (선택, "이 대사가 왜 좋았나요?")
- 공개 범위 선택 🔷: 나만 보기 / 팔로워에게 공개 (기본: 나만 보기)

**상태**: 본문 비어있으면 저장 버튼 비활성화.

---

## S-07. 대사 상세 (알림 설정) ⭐

**목적**: 대사 하나를 크게 보고, 알림을 설정한다.

**구성 요소**
- 상단: 뒤로가기 + (수정/삭제 메뉴)
- **대사 본문** (크게, 인용구 스타일)
- 등장인물 · 출처(책 제목/작가)
- 메모 (있으면)
- **알림 설정 영역** (핵심):
  - "이 대사를 언제 만날까요?"
  - 시간 선택 (시:분 피커)
  - 반복 선택: 매일 / 특정 요일 / 한 번
  - 요일 선택 (특정 요일일 때 — 요일 토글 버튼들)
  - 알림 on/off 토글
  - [알림 저장] 버튼
- 설정된 알림이 여러 개면 리스트로 표시

**상태**: 알림 없을 때 "알림을 설정하면 이 대사를 다시 만날 수 있어요"

---

## S-08. 팔로잉 피드 🔷

**목적**: 팔로우한 사람들의 공유 대사를 본다.

**구성 요소**
- 상단: "피드" 타이틀
- 대사 카드 리스트 (세로 스크롤):
  - 각 카드: 작성자 닉네임 + 프로필, 대사 본문, **출처(책 제목·작가) — 필수 표시**, 좋아요 버튼+수
- 카드 탭 → 대사 상세(읽기 전용)

**상태**
- 빈 화면: "팔로우한 사람이 없어요. 다른 독자를 찾아보세요" + [사용자 검색]
- 로딩: 스켈레톤

**⚠️ 필수**: 출처(작품 제목·작가)가 모든 카드에 반드시 보여야 함 (저작권).

---

## S-09. 프로필 / 설정 ⭐🔶🔷

**목적**: 내 정보, 팔로워/팔로잉, 설정.

**구성 요소**
- 내 프로필: 닉네임, 자기소개, 팔로워/팔로잉 수 🔷
- [사용자 검색] → 팔로우 🔶
- 설정 섹션:
  - 알림 기본 시간
  - 로그아웃
  - (앱 정보, 이용약관, 개인정보처리방침 — 출시 시)

---

## 공통 UI 규칙

- **하단 탭바** (로그인 후): 내 책장 / 피드 / 프로필 (3탭). 아이콘 + 라벨.
- **로딩은 스켈레톤 우선** (스피너보다 체감 빠름)
- **빈 화면(Empty State)을 반드시 디자인** — 특히 책장·피드. 첫 사용자 경험 좌우.
- **에러는 재시도 버튼과 함께** — 막다른 길 없이.
- **대사 본문은 항상 주인공** — 크고 읽기 좋게, 인용구 느낌.
