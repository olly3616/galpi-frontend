# 갈피 — 사용자 워크플로우 (User Workflow)

> 용도: **화면 간 이동과 사용자 흐름을 정의.** Claude Design(화면 연결)과 Claude Code(네비게이션 구현) 양쪽이 참고.
> 화면 ID는 `02_화면설계서.md`와 연결된다.

---

## 전체 네비게이션 구조

```
앱 시작
  │
  ├── (토큰 없음/만료) → Auth Stack
  │       ├── S-01 로그인
  │       └── S-02 회원가입
  │
  └── (토큰 유효) → Main (하단 탭)
          ├── [Tab1] 내 책장 Stack
          │     S-03 → S-04 / S-05 → S-06 / S-07
          ├── [Tab2] 피드 🔷
          │     S-08
          └── [Tab3] 프로필
                S-09
```

---

## WF-01. 앱 시작 & 인증 분기 ⭐

```
앱 실행
  → secure-store에서 토큰 확인
      ├── 토큰 있고 유효 → 내 책장(S-03)으로 바로 진입
      ├── Access 만료 + Refresh 유효 → 토큰 갱신(F-03) → S-03
      └── 토큰 없음/만료 → 로그인(S-01)
```

**포인트**: 매번 로그인 안 하도록, 저장된 토큰으로 자동 로그인.

---

## WF-02. 회원가입 → 첫 진입 ⭐

```
S-01 로그인 화면
  → "회원가입" 링크 탭
  → S-02 회원가입
  → 정보 입력 + [가입하기]
      ├── 성공 → 자동 로그인 → S-03 내 책장 (빈 화면)
      │         → "첫 책을 꽂아보세요" 유도
      └── 실패 → 인라인 에러 표시, 화면 유지
```

---

## WF-03. 로그인 ⭐

```
S-01 로그인
  → 이메일·비밀번호 입력 + [로그인]
      ├── 성공 → 토큰 secure-store 저장 → S-03
      └── 실패 → "이메일 또는 비밀번호가 올바르지 않습니다"
```

---

## WF-04. 책 추가 (API 검색) ⭐

```
S-03 내 책장
  → [+] 버튼
  → S-04 책 추가 (검색 탭)
  → 검색어 입력 → 결과 리스트
  → 원하는 책 [추가]
      ├── 성공 → 책장에 추가됨 → S-03로 복귀 (새 책 보임)
      └── 이미 있음 → "이미 책장에 있는 책입니다"
```

---

## WF-05. 책 추가 (직접 등록 = 웹소설) ⭐

```
S-04 책 추가
  → [직접 등록] 탭
  → 제목/작가/유형 입력 (+표지 선택 업로드)
  → [등록]
  → source=MANUAL로 저장 → 책장에 추가 → S-03 복귀
```

**포인트**: 검색 결과 없을 때 이 탭으로 자연스럽게 유도 (웹소설 배려).

---

## WF-06. 대사 기록 (핵심 흐름) ⭐

```
S-03 내 책장
  → 책 표지 탭
  → S-05 책 상세 (그 책의 대사 모아보기)
  → [+] 대사 추가
  → S-06 대사 작성 (등장인물/본문/메모/공개범위)
  → [저장]
  → S-05로 복귀 (새 대사가 리스트에 나타남)
```

---

## WF-07. 대사 알림 설정 (하이라이트) ⭐

```
S-05 책 상세
  → 대사 카드 탭
  → S-07 대사 상세
  → 알림 설정 영역
      → 시간 선택 + 반복(매일/요일/한번) 설정
      → [알림 저장]
  → 서버 quote_schedules 저장
  → (이후) 설정 시각에 서버가 FCM 푸시 발송
```

### 알림 수신 흐름 (푸시 → 앱)
```
설정 시각 도달
  → 서버 @Scheduled가 대상 조회 → FCM 발송
  → 폰에 알림 표시 (대사 본문)
  → 사용자가 알림 탭
  → 앱 열리며 해당 대사 상세(S-07)로 딥링크 이동
```

---

## WF-08. 사용자 검색 & 팔로우 🔶

```
S-09 프로필
  → [사용자 검색]
  → 닉네임 검색 → 결과 리스트
  → 사용자 선택 → 프로필(S-09 형태, 남의 것)
  → [팔로우]
```

---

## WF-09. 팔로잉 피드 보기 🔷

```
[Tab2] 피드
  → S-08 팔로잉 피드
  → 팔로우한 사람들의 FOLLOWERS 대사 최신순
      (각 대사에 출처 표기 필수)
  → 대사 카드 탭 → 읽기 전용 상세
  → 좋아요 가능
```

**빈 화면**: 팔로우가 없으면 → 사용자 검색으로 유도.

---

## WF-10. 로그아웃 ⭐

```
S-09 프로필 → 설정 → [로그아웃]
  → secure-store 토큰 삭제
  → S-01 로그인으로 이동
```

## 상태 전이 요약 (인증 관점)

```
[비로그인] --회원가입/로그인--> [로그인됨]
[로그인됨] --Access 만료--> [토큰 갱신 시도]
    [갱신 성공] --> [로그인됨]
    [갱신 실패] --> [비로그인] (재로그인 유도)
[로그인됨] --로그아웃--> [비로그인]
```

## 개발 우선순위 흐름 (이 순서로 구현)

1. **WF-01, 02, 03, 10** (인증 흐름 전체) ⭐ — 먼저 앱↔서버 연결 뚫기
2. **WF-04, 05, 06** (책장·책·대사 CRUD) ⭐ — 핵심 데이터 흐름
3. **WF-07** (알림 설정 + FCM) ⭐ — 하이라이트, 난이도 높음
4. **WF-08, 09** (팔로우·피드) 🔶🔷 — 여유되면
