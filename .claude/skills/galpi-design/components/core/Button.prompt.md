Primary action control — filled brown for the one main action per screen, outlined for the alternative, text for auth-style switches.

```jsx
<Button variant="primary" size="lg" fullWidth>책 추가</Button>
<Button variant="secondary" iconLeft="plus">대사 담기</Button>
<Button variant="text">이미 계정이 있어요</Button>
```

`loading` shows an inline spinner (never a full-screen overlay). Disabled primary flattens to grey + 45% opacity.
