Thin outline glyph (Lucide) that inherits text color — use for every icon in 갈피 rather than emoji or hand-drawn SVG.

```jsx
<Icon name="bookmark" size={20} />
<Icon name="bell" size={16} color="var(--text-secondary)" />
```

Icons are CSS-masked so `color` on the parent tints them. Core set: `book-open`, `bookmark`, `bell`, `heart`, `plus`, `search`, `user`, `sticky-note`, `chevron-left`.
