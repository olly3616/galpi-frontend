Centred invitation for any empty list — the most important state in 갈피.

```jsx
<EmptyState icon="library" title="첫 책을 책장에 꽂아보세요"
  description="좋아하는 구절을 담아둘 책을 골라주세요" action={<Button iconLeft="plus">책 추가</Button>} />
```

Title is serif and warm; copy invites rather than reports ("없습니다" → "…보세요").
